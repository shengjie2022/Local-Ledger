启动方式

解压后双击 index.html；或 Windows 双击“启动账本.bat”。安装 Python 3 后也可运行“python 启动账本.py”，访问 http://127.0.0.1:8899/。纯前端无需安装 npm 依赖。

发现与修复

问题处理
存储降级后重启退回旧数据IDB 和 localStorage 副本增加版本号，读取较新数据；串行保存并在调用时拍快照，内存降级可读回。兼容旧格式。
手动账目进入错误账户保留“微信·零钱”等完整账户名，不再移除平台前缀；手动金额限制到分，拒绝无效日期。
备份恢复可破坏当前账本校验交易、设置和规则后再替换；损坏备份不修改当前数据；恢复前提示覆盖，正确处理旧版基准日，并同步筛选和规则控件。
自定义划转账户被强改成微信按规则模板替换支付方式，支持支付宝和其他账户前缀。
导出文本可能被表格软件当成公式对公式起始的文字加文本前缀，金额保持数字；普通 CSV 引号继续转义。
切到后台时尚有待保存修改立即提交待保存快照，减少防抖计时内关闭页面造成的丢失窗口。

  • 真实 IndexedDB 模拟写失败且删除失败，写入备用副本后重新加载，较新账目与设置保持不回退。

交付边界与迁移

浏览器数据按地址与端口隔离，换端口或换浏览器前请从旧版本导出 JSON 备份，在新版本恢复。备份恢复会替换当前账本。新版本的内部存储信封格式不适合直接降级旧代码，回滚应使用导出的标准备份。CSV 文本前缀用于首次导出，表格软件另存并重开可能改变其解释。Windows 批处理及真实个人账单仍待人工确认。

原始 RAR 未修改。交付包排除旧构建、node_modules、Git 历史、索引、个人配置、密钥、虚拟环境和临时验证资料。旅游包中的 dist 为本次新构建产物。没有发布网站或合入 main。
