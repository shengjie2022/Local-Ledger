    怎么导出账单
    微信：微信 → 我 → 服务 → 钱包 → 账单 → 右上角「…」→ 账单明细 → 常见问题 → 下载账单 → 选「用于个人对账」→ 选时间范围 → 接收账单。
    支付宝：支付宝 → 我的 → 总览 → 右上角「账单」→ 右上角「…」→ 开具交易流水证明 → 选择时间段 → 导出账单（CSV）。

    余额是怎么反推的
    你只需要填"现在还剩多少钱"（基准余额）。账本从最后一笔交易往前倒推：
    某笔交易前的余额 = 该笔后的余额 − 该笔的资金变动。收入往前推会变少，支出往前推会变多。

    基准日
    默认取最后一笔交易的日期。如果你的账单没更新到今天，请把基准日改成"账单覆盖的最后一天"，否则反推出来的余额会偏大。 基准日一旦你手动改过就不会再被自动覆盖，想恢复自动点旁边的「↺ 最后一笔」。

    同一个文件导了两遍
    账本会比对文件的内容指纹，发现是同一个文件会弹窗提示，默认跳过 —— 重复导入会让收支直接翻一倍。

    账本体检
    导入后先看一眼「账本体检」：它会替你找出缺了哪个月的账单、哪个文件重复导了、 哪笔"不计收支"没匹配到划转规则、哪笔部分退款金额查不到 —— 这些问题在原始表格里看不出来。

    两个口径的区别
    「按账户分别」：每个账户（微信·零钱、微信·××银行卡、支付宝…）各自填余额，各自倒推，最贴近"这笔消费前我零钱里还有多少"。
    「全部合计」：所有账户合并成一个总资产倒推。

    不计收支 / 内部划转
    零钱充值、零钱提现、余额宝转入转出这类行，账单里标的是"不计收支"，它不改变总资产，但会改变某个具体账户。规则表里可以调整它落到哪个账户、什么方向。

    数据存在哪
    全部存在这台电脑的浏览器里（IndexedDB），不联网、不上传。换浏览器或清缓存会丢，请定期用「导出 → 完整备份 JSON」存一份。

    🧾

    还没有账本数据

    把微信、支付宝的「账单明细」文件拖进左边，账本就会自动生成。

    1. 导入账单文件（支持多个，一次全拖进去）
    2. 在「余额反推」里填上你现在实际有的钱
    3. 按日 / 月 / 年查看流水，每笔都能看到支出前的余额
